# توريد (Tawreed)

منصة B2B تربط الشركات والموردين بالتجار (سوبر ماركت، هايبر ماركت، محلات) في مصر لتسهيل الطلب والتوريد المباشر.

## التقنيات المستخدمة (Tech Stack)
- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS v4**
- **Lucide React** (Icons)
- **Google Fonts** (Cairo)

## التشغيل المحلي (Getting Started)
```bash
npm install
npm run dev
```

افتح المتصفح على [http://localhost:3000](http://localhost:3000).
